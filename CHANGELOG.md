# Changelog

## 0.2.0

- Add spin-unrestricted electronic GF2 and coherent-state QED-GF2 for open-shell molecules.
- Add exact and density-fitted unrestricted self-energy/Fock kernels, spin-resolved population and convergence reporting, and example inputs.
- Retain restricted mode as the default and restricted LF-GF2 behavior.
- Include the coupled restricted chemical-potential solver merged after 0.1.1.

The release tag and publication should follow review and a passing release build.
